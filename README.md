# 📚 Safeer Quran Academy — React Frontend

A complete Quran Academy management system with **Student Portal** and **Faculty Portal** for managing students, fees, attendance, results, and notices.

## ✨ Features

### 🎯 Public Website
- Responsive navbar with mobile menu
- Hero section with course highlights
- Stats section (24+ Courses, 50+ Teachers, 10+ Years)
- Teacher profiles (Safeer Khan & Shahana Safir)
- 6 course cards grid
- Free trial CTA section
- 4-column footer
- About Us page with values
- Contact form with map info

### 🎓 Student Portal
- Dashboard with progress tracking
- Profile management (edit personal info)
- Course progress with Surah/Juz tracking
- Fee payment tracking (total/paid/remaining)
- Attendance view with percentage
- Results & grades
- Notices & announcements
- Class schedule

### 👨‍🏫 Faculty Portal
- Secure faculty-only login
- Student list with search functionality
- Student approval system
- Progress & teacher notes update
- Fee management (record payments)
- Notice publishing (normal/high priority)
- Results entry with automatic grade calculation
- Schedule management
